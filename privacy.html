隱私權政策

適用於「資產管理」個人自用程式。最後更新：2026-10-26。

使用者

本程式只供擁有者本人使用，不開放其他人授權或使用。

存取的資料

經擁有者本人授權後，以 Gmail 唯讀權限（gmail.readonly）讀取擁有者自己信箱中的特定信件與附件。本程式不寄信、不刪信、不修改任何信件或設定。

資料的使用與保存

讀取的資料只在擁有者自己的電腦上處理與保存，用於整理擁有者本人的財務紀錄。不上傳到本程式的任何伺服器（本程式沒有伺服器），不分享、不出售給任何第三方，也不用於廣告。

撤銷授權

擁有者可隨時在 Google 帳戶的「第三方存取權」頁面移除本程式的存取權。

Google API 服務使用者資料政策

本程式使用從 Google API 取得的資訊時，遵守 Google API 服務使用者資料政策，包括有限使用規定。

Privacy Policy (English)

This tool is used only by its owner. With the owner's consent it reads specific messages and attachments in the owner's own Gmail using the read-only scope (gmail.readonly); it never sends, deletes or modifies mail. Data is processed and stored only on the owner's own computer, is not uploaded to any server, and is never shared or sold. Access can be revoked at any time from the Google Account third-party access page. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
